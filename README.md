# Pavia Cricket Tournament 2026 – Poster

## Files
- `pavia_cricket_2026.html` – Full poster with embedded logo (open in any browser)

## Design
- **Theme:** Premium Black × Red × Gold sports poster
- **Background:** Dark charcoal with red + gold gradient accents
- **Watermark:** Pavia Cricket Tournament logo (transparent, center)
- **Font:** Bebas Neue (headings) + Barlow Condensed (matches)
- **Layout:** Structured match cards with time strips and team names

## Usage
Open `pavia_cricket_2026.html` in a browser. For printing:
- Use Chrome → Print → Save as PDF
- Set paper to A3/A4, margins to None, enable "Background graphics"
